お試し3袋を無料にするクーポンです。同梱するアンケート名と利用上限を設定します。

レビュワー用クーポンの設定

Reviewerに続けて、半角英数字2〜50文字を入力します。

80文字まで。注文一覧と発送画面に表示します。

回

1〜10,000回で指定してください。このコード全体で使える回数です。個別配布には、相手ごとに異なるコードを上限1回で発行できます。

通信が途切れ、発行結果を確認できません。同じ登録番号で確認するため、二重に発行しません。
