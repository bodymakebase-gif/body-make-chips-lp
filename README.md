# BODY-MAKE CHIPS LP

BODY-MAKE CHIPSの公式ランディングページです。

- 公開基盤：GitHub Pages
- 正式URL：https://body-make-chips.jp/
- 正式ドメイン：`body-make-chips.jp`（wwwなし）
- 公開元：`main`ブランチのリポジトリルート

## 2026年11月18日：レビュー機能

レビュー欄には表題を表示せず、平均評価と投稿ボタンを表示します。投稿の入口は「レビューを書く」に統一。閉じている間は上部ボタンだけ、開いている間はフォームの開閉見出しだけを表示し、重複をなくしています。

LPのセット一覧の直前に、星1〜5・コメント・画像3枚までの投稿、平均評価と評価分布、参考票順／新着順の一覧を追加しました。最初は4件を表示し、「もっとレビューを見る」で4件ずつ追加します。本文は3行まで表示し、4行目以降は「続きを読む」で展開・「閉じる」で折り畳めます。投票ボタンの表示は親指のアイコンと件数だけです。投稿フォームと画像拡大はLP内で完結します。画像は送信前にブラウザーで縮小・JPEGへ再保存します。

一般投稿は承認待ちで保存され、公開中のレビューだけが件数・平均・並び順に反映されます。管理画面の「レビュー」タブでは件数制限なく追加・編集・承認・非公開・削除ができ、元の投稿日、引用元URL、商品提供モニター等の区分、画像を設定できます。掲載元のサイト名・リンク・区分バッジはLPに表示せず、管理画面で記録として保持します。投稿フォーム内の見出し・導入文は削除し、評価欄は枠なしの黄色い星を選ぶ形式にしています。外部レビューの評価は原文に沿って入力してください。架空レビューは本番データに登録していません。

- 公開UI：`reviews-client.js`、`reviews.css`、`index.template.html`（`node build.mjs`でHTML生成）。
- 保存処理：`checkout-server/src/reviews.mjs`。既存在庫とは別のSQLite Durable Object `Reviews` に保存し、購入処理や在庫数を変更しません。
- 公開Origin／Turnstile／管理画面認証の接続：`checkout-server/src/reviews-gateway.mjs`、`worker.mjs`、`admin.mjs`。
- 一般投稿は同じブラウザーから24時間に1件、参考票は同じブラウザーで各レビュー1票（取り消し可能）。管理者の登録件数制限はありません。これらは本人確認による厳密な1人1票ではなく、ブラウザー識別子・レート制限・Turnstileで重複や不正を抑えるものです。
- 画像は元ファイル10MB以下、送信時は1枚300KiB以下、最大3枚。サーバーでも形式・寸法・容量を検査し、未公開レビューの画像は管理者だけが閲覧できます。
- 自動テスト：`cd checkout-server` → `node --test test/*.test.mjs`。本番バンドル確認：`node node_modules/wrangler/bin/wrangler.js deploy --dry-run --config wrangler.live.toml`。

本番反映時はCloudflare認証を確認し、追加migration `v2-reviews` を含むWorkerを先に公開・確認した後にLPを更新します。元のInventory名前空間・Secretsを維持してください。ローカルの確認用サーバー・仮の認証処理・検証用レビューDBは本番に含めません。

## 更新方法

サイト改修は従来どおり、このGitHubリポジトリ内のHTML、CSS、JavaScript、画像を編集します。公開元ブランチへ反映すると、GitHub Pagesのビルド後に独自ドメイン側へも反映されます。

通常のコンテンツ修正ではDNS設定を変更しません。リポジトリルートの`CNAME`ファイルは削除したり、別のドメインへ書き換えたりしないでください。
